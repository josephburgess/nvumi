*nvumi*    Natural language calculations in Neovim
=================================================

nvumi integrates the [numi-cli](https://github.com/nikolaeu/numi) natural language
calculator with a scratch buffer. Type natural language expressions and see the
evaluated results either inline or on a new line as you type.

USAGE
-----

    :Nvumi

This command opens a scratch buffer where you can enter your calculations.

  - Expressions are automatically evaluated as you type.
  - Press `<CR>` in normal mode to re-evaluate/refresh all non-empty lines.
  - Press `R` in normal mode to reset the buffer (clears all content and variables).
  - Press `<leader>y` in normal mode to yank the evaluation of the current line.
  - Press `<leader>Y` in normal mode to yank all evaluations.
  - Press `q` to close the buffer (content is persisted across sessions).

VARIABLE ASSIGNMENT
-------------------
*nvumi-variable-assignment*

nvumi supports assigning evaluated expressions to variables, letting you reuse
previously computed values in your calculations.

To assign a variable, write a line in the form:

    variable_name = expression

Example:

    x = 2+2
    x * 3

nvumi substitutes `x` with its stored result before evaluation. Variables are
cleared when you reset the buffer (`R`).

CUSTOM CONVERSIONS
------------------
*nvumi-custom-conversions*

nvumi supports user-defined unit conversions, allowing you to add your own units.

- Define custom units with aliases, a base unit group, and a conversion ratio.
- Custom conversions must share the same `base_unit` (e.g., `"speed"`, `"volume"`).
- Ratios are relative to the base unit.

Example configuration:

>lua
  custom_conversions = {
    {
      id = "liters",
      phrases = "l, liter, liters",
      base_unit = "volume",
      format = "L",
      ratio = 1,
    },
    {
      id = "gallons",
      phrases = "gal, gallon, gallons",
      base_unit = "volume",
      format = "gal",
      ratio = 3.78541, -- 1 gallon = 3.78541 liters
    },
    {
      id = "kmh",
      phrases = "kmh, kmph, klicks, kilometers per hour",
      base_unit = "speed",
      format = "km/h",
      ratio = 1,
    },
    {
      id = "mph",
      phrases = "mph, miles per hour",
      base_unit = "speed",
      format = "mph",
      ratio = 1.609344, -- 1 mph = 1.609344 km/h
    },
  }
<

Examples:

    10 gallons in liters   →   37.8541 L
    5 kmh in mph           →   3.10686 mph

CUSTOM FUNCTIONS
----------------
*nvumi-custom-functions*

nvumi supports user-defined functions with aliases. Functions can accept numbers,
strings, or no arguments, and can surface errors via an `error` key in the return.

Example configuration:

>lua
  custom_functions = {
    {
      def = { phrases = "square, sqr" },
      fn = function(args)
        if #args < 1 or type(args[1]) ~= "number" then
          return { error = "square requires a single numeric argument" }
        end
        return { result = args[1] * args[1] }
      end,
    },
    {
      def = { phrases = "hello, hi" },
      fn = function(args)
        local name = args[1] or "stranger"
        return { result = "Hello, " .. name .. "!" }
      end,
    },
    {
      def = { phrases = "coinflip, flip" },
      fn = function()
        return { result = (math.random() > 0.5) and "Heads" or "Tails" }
      end,
    },
  }
<

Example output:

    square(4)              →  16
    hello("Joe")           →  Hello, Joe!
    hello()                →  Hello, stranger!
    square("text")         →  Error: square requires a single numeric argument
    flip()                 →  Heads | Tails

Note: functions using randomness (like `flip`) will re-evaluate each time the
buffer is refreshed. This is expected behaviour.

INLINE `{}` EVALUATIONS
------------------------
*nvumi-inline-evaluations*

Any expression inside `{}` is evaluated first and the result is substituted into
the full line before processing. This is useful when passing computed values as
function arguments.

    {10+20} mph in kmh    →   30 mph in kmh  →  48.28032 km/h
    log({10*10}, {5+5})   →   log(100, 10)   →  2

CONFIGURATION
-------------
*nvumi-configuration*

nvumi supports the following configuration options:

>lua
  {
    "josephburgess/nvumi",
    opts = {
      virtual_text = "newline", -- or "inline"
      prefix = " = ",           -- prefix shown before output
      date_format = "iso",      -- or: "uk", "us", "long"
      width = 0.4,              -- 0–1 = fraction of terminal width, >1 = absolute columns
      height = 0.4,             -- 0–1 = fraction of terminal height, >1 = absolute lines
      keys = {
        run = "<CR>",           -- run/refresh calculations
        reset = "R",            -- reset buffer and clear variables
        yank = "<leader>y",     -- yank output of current line
        yank_all = "<leader>Y", -- yank all outputs
      },
      custom_conversions = {},
      custom_functions = {},
    }
  }
<

REQUIREMENTS

MacOS:

  brew install nikolaeu/numi/numi-cli
<

Linux / Windows:
>bash
  curl -sSL https://s.numi.app/cli | sh
<
